# ビジネスの画面 デザインレビュー（2026-10-17）

対象：中央の「ビジネス」タブ（`src/renderer/business/`、`src/renderer/styles/business.css`）。
方法：高速 E2E のハーネス（`e2e-fast/harness`、fixtures の BusinessApi）を 1440×900 で撮り、画像を目で見て直した。ダークとライトの両方。狭い幅（中央 760px 相当）も1回見た。
見本データは架空（fixtures）。本物の main・Agent・Worker にはつないでいない。

## 見たもの

- ダッシュボード（ループ S1〜S10・周回・前の周の変更、仮説の表、実施中の実験の経路の数、記録の注意、承認待ちの案内）
- 仮説のフォーム（D/A/P の採点表、根拠の証拠の選択、段階を進めるボタン）
- 実験のフォーム（計画と実測の2列、計算と判定、実験ページ）
- 承認（待ちの選択肢・回答・承認／却下、決めたものの表）
- ステップパネル（出口の確認・データ・プロンプトの全文・送り先・送れなかったときの表示）
- ダイアログ（段階を進める、周を閉じる、保存していない変更）
- ビジネスでないプロジェクト（ビジネスを始める）、空のビジネス

## 見つけたことと直したこと

| # | 見つけたこと | 直したこと |

## 確かめた決まり（ferret-lessons.md）

- 段組は「本文＋右のステップパネル」の2列。パネルは画面に固定せず本文と一緒に流れる。畳むボタンはパネルの中、開くボタンはナビの右端。中央が 860px より狭いとパネルは本文の下へ回る
- ナビ・ボタン・札は1行（`white-space: nowrap`。ナビは横に流れる）。説明文は置かず、用語はツールチップ（点の項目、根拠の性質、D/A/P の見出しなど）
- U を 0 と出さない（表・パネル・フォーム）。未計測・未成立は文字で出し、0 円と出さない
- 送れなかったら送れなかったと出す（トーストとパネルの文の両方）。新しい Agent は起動を待ってから送り、起動できなければ送らない
- 生の英語のエラーとファイルのパスは出さない（`errorText`）
- 読み込みの輪は出さない。読み直しの間も前の中身を出し続ける。開いている記録がほかで変わったら、編集中なら「読み直す」を出し、編集中でなければそのまま映す
- 保存していない状態は「未保存」の札で示し、離れるときは確認する

## 残したこと（本人の確認待ち）

- ダークの主ボタン（白地に黒）は、アプリ全体の主ボタンと同じ見た目のまま。ビジネスの画面だけ変えることはしていない
- ループのステップ名は狭いと「…」で切れる。2行にはしていない（教訓に合わせた）
- 段階を進めるダイアログの「進める」は、確認のチェックを入れるまで押せない（薄く見える）

# 外枠をビジネス向けにする（2026-10-17・2回目）

実機（`pnpm build` → Playwright の `_electron`、`ADE_E2E=1 ADE_E2E_SHOW=1`）で、起動・ビジネスのダッシュボード・内蔵ブラウザ・設定・ビジネスが無い起動を撮って見た。構想 5章「外す・止める」に合わせ、UI レビューの流れは renderer で隠し、main 側のコードは残した（`App.tsx` の `REVIEW_UI`）。

## 前（本人の画面）→ 後

| 場所 | 前 | 後 |
|---|---|---|
| タイトルバー | エディタ／フィードバックの切替、赤い「録画」、「文字で指摘」 | ロゴ・ビジネス名・今のステップ・パネルの開閉・設定だけ |
| 中央のタブ | ビジネス・ブラウザ・指摘 | ビジネス・ブラウザ（ページ名。空のときは「ブラウザ」） |
| ブラウザの空の画面 | 「レビューする画面を開く」＋説明文＋localhost の候補 | 「調べるページの URL を入れる」＋［URL を入力］（⌘L の手がかり）。最近開いた URL だけ |
| ブラウザのツールバー | 「文字で指摘」 | ビジネスのフォルダのときだけ「証拠に追加」。読了／発見のみをそのまま知らせる |
| フッター | 00:00・マイク・端末内／whisper small・発信・v0.6.30 | 使用量・リソース・ページ・配置・v0.1.0（package.json）。版を押しても更新の確認は出さない |
| サイドバー | 「プロジェクト」、「すべてのプロダクト」、セットアップ 4/8 | 「ビジネス」、全体（オーケストラ）は出さない、＋はフォルダを選ぶ、セットアップは Agent とフォルダの2つ |
| 起動先 | 全体（すべてのプロダクト）のダッシュボード | 最後に開いたビジネス。無ければ中央に「フォルダを選んでビジネスを始める」 |
| ループの札 | 10列で「対象...」「証拠...」と切れる | 2段×5（発見／アクション・チェック）。全部の名前が1行で出る（実機で S8「有料試行・集客」の切れ無しを確認） |
| 設定 | 見出し「録画と文字起こし」、録画・文字起こし・整理・判定モデル・全体の節、録画の保管期間 | 見出し「設定」。上の節と録画の行を出さない |
| メニュー | 録画（⌘⇧R）・モード切替（⌘⇧M）・レビュー対象（⌘⇧K） | 無し（メニューからも隠した画面を開けない） |
| 初回のセットアップ | 配色・Agent・判定モデル・プロジェクト（URL 登録）・文字起こし・許可・完了 | Agent・フォルダ・完了。説明文と製品の考え方の3段は外した |

撮った画像（実機）：scratchpad の `real3/1-start.png`〜`7-settings-layout.png`、`real5/0-no-business.png`。

## 見つけて直したこと（実機で）
- 新しいフォルダを開くとブラウザのタブ（about:blank）に着地していた → フォルダを開いたらビジネスのタブを前に出す。
- タブ・フッターに「about:blank」が出ていた → 空のときは「ブラウザ」「ページなし」。
- URL 欄の見本が `http://localhost:3000` だった → `https://`。
- 設定の見出しが「録画と文字起こし」だった → 「設定」。
- 証拠の知らせが4行に折れた → 「E01 を「発見のみ」で追加しました」の1文。
- ビジネスが無いとき、全体のフォルダの中身（feedback・README）がファイル一覧に出ていた → 出さない。
- 同じ「フォルダを選んで始める」がサイドバーと中央に2つあった → 中央だけ。

## 残したこと
- フッターの使用量（「46% used 18m」）が英語のまま。
- 設定の一番上の settings.json の欄に、Ferret の設定 skill（確認先の URL などに触れる説明）が出る。
- ファイル一覧の空の文「プロジェクトフォルダを開くと…」など、外枠の細かい文言に「プロジェクト」が残る。
- 版を 0.1.0 にしたので、main の更新の確認（本家 Ferret の配信元）は 0.6.x を新しい版とみなす。画面からは出さないようにしたが、配布版（IS_PACKAGED）では自動更新が動くので、配る前に updateCheck を止めること（構想 5章）。
- 内蔵ブラウザのページは別のビューなので、画面の写しには写らない（動作は「証拠に追加」の結果で確認）。
