Ferret 0.6.28

- Agents: Antigravity (`agy`) now takes Gemini CLI's place. Google stopped Gemini CLI sign-in with a personal Google account and points people to Antigravity, so Antigravity is listed with the main agents, and usage-limit failover now goes Claude Code → Codex → Antigravity by default. If you saved your own failover order, Ferret keeps it. Gemini CLI stays in the list for API key and Vertex AI users.
- Agent mail: you can address Antigravity as `antigravity` or `agy`.
- Terminal: Ctrl+J adds a new line in Antigravity's prompt without sending it.
- Windows: Ferret can now install Antigravity for you, using Google's own install command.
