Ferret 0.8.30

- Fixed an error in the TypeScript and JSON editor that could appear when code lenses or the outline loaded for the first time.
- Ferret account: if syncing feedback is cut off partway (a dropped connection, a timeout, or a Wi-Fi login page or proxy answering instead of Ferret), it is now treated as a connection problem and tried again on the next sync, instead of being reported as an unexpected response.
- Responses from the usage meters, local models, the feedback relay and shared reviews are now read with the same size limit and the same handling of cut-off connections.
- Crash reports: short pauses right after another app turns on accessibility features (Chromium rebuilds its accessibility tree then) and child processes that exit while an update is being installed are no longer reported.
