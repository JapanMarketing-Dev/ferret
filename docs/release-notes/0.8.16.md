Ferret 0.8.16

- After you stop a recording, Ferret now shows how far along the review is, from 0 to 100%, next to the record button. It shows what it is doing (saving the audio, transcribing the rest, putting findings and images together) and which project the recording belongs to, so you can see it is still working even after switching to another project. It disappears once the review is ready.
