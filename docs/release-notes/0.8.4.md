Ferret 0.8.4

- Right-clicking a project or orchestra near the bottom of the sidebar now shows the whole menu, so "Archive" and "Delete" can be reached again (the menu used to run off the bottom of the sidebar).
- The menu item is now called "Delete", and its confirmation says it can't be undone; use "Archive" for anything you may want back. Deleting never removes the folder.
- Archived projects and orchestras can be deleted too: right-click one under "Archived" for "Restore" and "Delete".
- Agents now learn from the feedback you already gave. Ferret collects what you said in visual reviews, value use cases and recorded reviews across all your registered projects, and a new agent skill (ferret-feedback) has agents read it before they plan or build, applying the related and recurring points up front (for example "shorter descriptions" or "fewer banners") so you don't have to repeat them. The list is refreshed when Ferret starts and when you add or remove projects.
