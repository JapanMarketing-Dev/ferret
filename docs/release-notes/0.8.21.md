Ferret 0.8.21

- Agents keep running until you close them. After Ferret restarts (including restarting to update), agents in projects you are not looking at now start again in the background and continue their conversation, instead of waiting until you open that project. Plain shells still start when you open their project. If memory runs low, Ferret shows the memory notice and you decide what to stop.
- The sidebar now shows when Antigravity and Qwen Code are working. Antigravity's "Generating" line changes its dots and letters every moment, so it was rarely caught. Ferret now also reads the "esc to cancel" status line, and shows the "done" mark when these agents finish.
