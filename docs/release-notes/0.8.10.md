Ferret 0.8.10

- Recording a screen or another window no longer flickers. When you switch what you record, the preview keeps showing the previous picture until the new one has its first frame, instead of going dark for a moment.
- A new preview stays hidden until its picture is ready, so the built-in browser shows until then instead of a dark box.
- Opening a menu, a popover or a dialog while recording no longer makes the preview blink when it closes.
- Fixed an error report sent when recording the whole screen started.
- Crash reports for a stalled app no longer blame unrelated work that had already finished.
