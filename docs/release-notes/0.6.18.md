Ferret 0.6.18

- Faster while recording: the whole window no longer redraws ten-plus times a second for the mic level and the timer. Only the meter and the clock update.
- Faster start: Settings, the orchestra dashboard, onboarding and meeting import load when you first open them (preloaded once the app is idle). The app screen also starts loading while browser extensions are still being prepared.
- Lighter background work: the agent-to-agent mailbox is watched instead of being checked 2.5 times a second, terminal output is cleaned once per chunk instead of twice, and large folders sort faster in the file tree.
- Fixed: crash reports from programs started in Ferret's terminals (such as a Playwright browser) were sent as Ferret crashes on macOS. Only Ferret's own processes are reported now.
- Fixed: on Windows, agent-to-agent requests quoted file paths in a way PowerShell expands, so a folder name containing `$` pointed somewhere else.
- Fixed: two quick saves of imported passwords, browsing history or share links could interfere with each other and lose the file.
- Fixed: starting Ferret from a folder reached through a link made the app refuse its own screen's requests.
- Fixed: the microphone menu in the status bar scrolled sideways; the file menu in the explorer left a listener behind each time it opened.
