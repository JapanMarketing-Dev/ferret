Ferret 0.8.3

- Visual review and Value use cases are now an infinite whiteboard instead of a long page, so you can see the whole plan at once. Drag or two-finger scroll to move, pinch or ⌘+scroll to zoom, double-click a card to zoom to it, and use "Fit all" / 100% at the top right. Value use cases show each value as a row, with its steps linked left to right by arrows; Visual review places the screens side by side, with each change as a note linked to its box by a dotted line. Approve and Feedback float at the bottom, and the document list can be hidden to give the board more room.
- Visual review and Value use cases show up much sooner: the agent now writes a rough draft within its first few steps (marked "Drafting", not approvable yet) and fills it in while you watch; the tab opens as soon as the draft appears. Agents also use visual review for small visible changes, add an "After" screenshot when they finish, and keep each value's status up to date after building.
- SSH projects now show a file tree on the right. Folders are read over SSH when you open them (the connection is reused, so it stays quick), and clicking a file opens it read-only in the editor; filtering by name works too. Changes are still made in the terminal.
- New projects are made in the left sidebar: choose PC or SSH, browse to a location, type a folder name and click "Create and make it a project", or open the current folder as is. For SSH, your saved SSH connections and the hosts in ~/.ssh/config are listed to pick from, or type user@host. The old folder dialog is still there as "Choose a folder…".
- Terminals and agents in SSH projects now run inside tmux on the remote machine, so they keep going when you close Ferret, put your PC to sleep or lose the connection. When Ferret reopens the tab it reattaches to the same session instead of starting the agent again. Closing the tab yourself ends the session; if the remote has no tmux, the tab says so and works as before.
