Ferret 0.6.23

- Phone remote: turn it on in Settings → Phone remote, then open the link or scan the QR code on your phone (same Wi‑Fi or Tailscale). From the phone, see every terminal and its agent's state (working, waiting, idle), read its screen, send instructions, and press Enter, Esc, arrows, 1/2/3 or Ctrl+C. It is off by default. The link carries a secret token, and Reset link invalidates old links. Use it only on networks you trust (plain HTTP; Tailscale is encrypted).
- Orchestra feedback knowledge: for products in an orchestra, Ferret keeps each review finding as one set in `feedback/`: the screenshot with your boxes and pen marks, the finding's text, what the agent did to fix it, and how you reacted (OK, NG, comments, reopen). Typed messages, requests and human.md answers are logged too. Agents read `feedback/playbook.md` before working on a product and distill new lessons into it, especially from fixes you rejected, so the next product starts from what you already said. Open both from the orchestra dashboard.
- Orchestra instructions: you set the frame (goals, value, scope); agents work inside it as testers, compare each product with its benchmark products in detail, report concrete gaps with evidence, and hand off work with an exact target and acceptance criteria.
