Ferret 0.7.5

- browser-use can now drive Ferret's built-in browser. In a Ferret terminal, the browser-use CLI controls the built-in browser instead of your Chrome, so Claude Code, Codex or any agent on your subscription can open pages, click, type and take screenshots step by step while you watch. Ferret brings the browser to the front when an agent starts.
- API mode: `ferret-browser "task"` hands a whole web task to browser-use's own agent in the built-in browser, using an API key saved in Ferret (Anthropic, OpenAI, Gemini, OpenRouter, Vercel AI Gateway) or a local Ollama / LM Studio model. The key stays in Ferret and is never given to the terminal.
- A ferret-browser skill for Claude Code and Codex explains both ways. Install browser-use once with `uv tool install --python 3.12 browser-use`.
- Only the built-in browser's tabs are exposed, on this computer only, behind a per-install token; Ferret's own window is never reachable.
