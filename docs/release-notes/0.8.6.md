Ferret 0.8.6

- Value use cases written in detail (hundreds of values, files over 1 MB) now open in the Value use cases tab instead of showing "cannot read". A file can be up to 16 MB and hold up to 1,000 values (was 1 MB and 30 values; values past 30 were silently dropped).
- When a value use case or visual review file cannot be read, the reason is now specific: too large (with its size and the limit), a link, not a regular file, or still being written, so the agent knows how to fix it.
