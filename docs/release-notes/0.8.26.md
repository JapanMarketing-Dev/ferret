Ferret 0.8.26

- Open a project in the ChatGPT, Claude or Gemini desktop app. Right-click a project in the sidebar (or use its ⋯ menu) and choose "Open in ChatGPT", "Open in Claude" or "Open in Gemini" to hand the project's folder to that app. Only the apps installed on your Mac are listed. This is available on macOS for local projects (not SSH projects).
- SSH projects: you can now create files and folders from the file tree on the right. Right-click a folder (or the empty space below the list) and choose "New File" or "New Folder", or use the buttons at the top of the tree. Names like `src/a/b.ts` also create the folders in between. Renaming, deleting and moving remote files are still not available.
- Codex scrolls like other terminals. Codex now starts without the alternate screen (`--no-alt-screen`), so the conversation goes into the terminal's own scrollback. Scrolling no longer jumps when Codex loads earlier messages. Codex tabs that are already open keep the old behaviour until you open them again.
