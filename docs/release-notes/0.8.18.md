Ferret 0.8.18

- Crash reports are more accurate. Opening Ferret again while it was already running (for example right after "Restart to update") could make the running window's session look like a crash. The second launch now quits before it starts crash reporting.
- Ferret no longer reports an error when a terminal's screen update is cut off because Ferret is quitting, such as when it restarts to install an update.
