Ferret 0.6.30

- Projects (Windows): registered projects and the orchestra no longer disappear when another program (antivirus, an editor or an agent) briefly holds the settings file. Ferret retries, re-reads the file once it can, and never overwrites it with an empty list.
- Quit (Windows): closing Ferret while it was still reopening terminals could crash it. Terminals no longer start once Ferret is quitting.
- Video trimming (macOS): trimming no longer times out while Ferret is in the background.
- Resource view (Windows): when the PC is busy, Ferret keeps reading process usage and tries again later instead of stopping.
