Ferret 0.7.7

- Fixed Ferret freezing for several seconds when you close a terminal tab, most often right after launch while many agents were starting. Ferret now looks up the tab's child processes in the background instead of waiting for them, so the window keeps responding.
- Opening many Claude Code tabs at once is faster: Ferret no longer re-reads a large `~/.claude.json` for every tab, and checks for an earlier conversation without blocking the app.
- Terminal output costs less work in the app, and the built-in browser no longer saves settings each time a page's title changes.
- Crash reports no longer count the time a Windows PC was asleep as a freeze.
