Ferret 0.8.0

- Feedback starts in one click: pressing Feedback records the whole display Ferret is on right away, with no picker. Switching windows or changing/unplugging the microphone no longer stops the recording.
- New Visual review tab: when you ask an agent to change the UI, it first shows the plan on the current screen (numbered boxes: what changes and how). Approve it or send feedback before any code is written. Ferret keeps the latest screenshot of each project's page so plans appear instantly.
- New built-in "work" folder for quick throwaway tasks, and a Global orchestra that covers every project: rules written there apply to all projects.
- Archive projects and orchestras to hide them without deleting anything; restore them any time. Orchestras and projects can be sorted separately (for example, orchestras by hand and projects by recent use).
- Opening an orchestra no longer starts Claude Code or Codex automatically.
- Excel, PowerPoint and Word files open as previews and can be edited and saved, including older formats (.xls, .ppt, .doc) and OpenDocument files when LibreOffice is installed.
- Agents can look across your other registered projects for reference (ferret-projects skill).
- File search is faster and always shows results; open files (including Markdown) update within about a second when changed on disk.
- Dropping files from Finder onto the editor now copies them into the project and opens them.
- Browser and Findings tabs sit apart from file tabs, and each project now keeps its own browser page.
- AI accounts: your normal login appears as a regular account you can pick, instead of "System default".
- The GitHub indicator in the footer no longer spins forever.
- Removed: Publish (post drafts), agent-to-agent requests, and the orchestra dashboard's findings, costs and monthly stats (request templates remain). The terminal can be hidden with Ctrl+` or the eye button in its header.
- Faster and lighter: smaller app code, editors load only when used, and far fewer background checks while idle.
