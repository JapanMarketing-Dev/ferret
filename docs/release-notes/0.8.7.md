Ferret 0.8.7

- Visual review and Value use cases: you can now copy where something is and paste it into Claude Code, Codex or any agent. A small link button copies the folder path for all documents (top of the list), one document's path (next to its title), or a single value, step, screen or change (on its card), as the file path plus the position inside it, e.g. `…/.ferret/value-usecases/app.json → values[1].flow[2] "Send invoice / Confirm"`.
- Fixed the built-in browser's memory watch failing every 30 seconds in 0.8.6, so background tabs are put to sleep again when memory runs high.
- Phone remote now listens only on your computer's Tailscale address, never on the local Wi-Fi network (the connection is plain HTTP). If Tailscale is not running, the port stays closed and Settings explains how to set it up; Ferret starts listening once Tailscale connects. The feature is still off by default.
- Updated dependencies with known security advisories (DOMPurify, fast-uri, undici, glob, minimatch).
- SECURITY.md now uses the Ferret name, points to GitHub private vulnerability reporting, and explains that agents skip permission prompts by default and how to turn that off in Settings → Agents.
