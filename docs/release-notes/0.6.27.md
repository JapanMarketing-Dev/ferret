Ferret 0.6.27

- Checking fixes: once you press OK on a finding, it stays done. Before, an agent that rewrote progress.json could set an OK'd finding back to waiting for your check. Ferret now keeps your verdicts in its own file and restores them. Moving a finding back from done yourself still reopens it.
- Checking fixes: in the BEFORE / AFTER view, the OK button stays in the same place for every finding, so you can press OK one after another. Long agent notes scroll inside the box.
- Local models: Ferret no longer applies its rate limits to local models, such as clef / clef-flash in Ollama, LM Studio, or a server on your LAN or Tailscale. The decision model's per-terminal and per-day call, token and cost limits, the transcription cost cap for a local server, and usage-limit failover are skipped for them. Cloud providers keep the same limits.
