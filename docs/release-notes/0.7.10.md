Ferret 0.7.10

- Claude Code and Codex that have been waiting for input for 30 minutes in a project you are not looking at now go to sleep to save memory. Ferret remembers their screen, and opening the project starts them again with the same conversation. Restored tabs of projects in the background also wait until you open the project. You can turn this off in Settings (it only works while terminal restore is on).
- Updated Electron, the terminal component (node-pty), crash reporting and other bundled libraries to their latest versions.
