Ferret 0.8.27

- SSH projects: you can now edit and save files. Markdown and other text files open in the preview or the source view as in local projects, and saving (⌘S / Ctrl+S, or "Save and quit" when closing Ferret) writes the file on the remote machine over SSH. The file is first received into a temporary file next to it and checked, so a dropped connection does not leave it half-written. Changes made on the remote machine by someone else are not detected while the file is open.
