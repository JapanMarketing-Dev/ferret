Ferret 0.8.13

- Agents in different projects can now use the built-in browser at the same time. Before, the built-in browser could only be driven from the project shown in Ferret, so an agent in another project's terminal could not use it. Each project now has its own set of browser tabs: an agent works in its own project's tabs, even while you are looking at another project, and never sees other projects' tabs.
- Switching projects no longer closes the tabs of the project you leave. They stay in the background (pages you are not using are put to sleep to save memory), and switching back shows them again, including any tab an agent opened.
