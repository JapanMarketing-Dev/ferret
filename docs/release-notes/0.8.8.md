Ferret 0.8.8

- Value use cases are now grouped, so a document with hundreds of values can be reviewed roughly, group by group. The tab first shows 10–30 group cards — each with its name, a one-line summary, how many values it holds, a bar of how many work / are partial / broken / not built, and the first few value names. Open a group to see its values and flows, or open or close them all at once.
- Agents now put every value into one of 10–30 groups when they write value use cases (and add groups to existing documents when they update them). Documents without groups are grouped automatically — by who the value is for, or otherwise in order — until the agent adds real groups.
- Each group has "Feedback on this group" (starts your feedback with the group's name, so the agent applies it to every value in it) and a button that copies the group's location to paste into an agent.
- Only the screenshots of opened groups are loaded, so large documents open quickly.
