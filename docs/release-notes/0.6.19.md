Ferret 0.6.19

- Publish to X from Ferret. Press Publish in the status bar, or Post to X above a file in the editor (it uses the selection if there is one). The AI writes post drafts from your recent changes (commits and README) or from the open text, with an optional note such as "announce the new release", and can pick images from the project. While the project is open it keeps a few drafts ready in the background when there are new commits (turn this off in Publish). Pick a draft, edit it, add up to 4 images or a video, and press Post to X: Ferret opens the X post screen in the built-in browser and fills in the text (split into a thread when it is longer than one post, counted the way X counts) and the media. You check it and press Post there. The paid X API isn't used. The AI is the one you chose for organizing feedback (Codex, Claude Code or an API key).
- Drafts are kept per project as Unused, Posted or Dismissed. Log in to X once in the built-in browser; if you aren't logged in, Ferret tells you instead of filling in the screen.
