Ferret 0.7.9

- On Windows, the first terminal you open after an update no longer freezes the window for several seconds. Ferret now has the system check its terminal components in the background right after it starts.
- If the usage check for Claude Code or Codex times out, the footer now says it could not connect, instead of saying the response had an unexpected format.
- Crash reports no longer report a timed-out or cancelled request as an error, or a graphics process that restarts after the display or sleep state changes. Short pauses while Windows is limiting CPU speed to save power are not reported as freezes either.
- Startup-time reports now show when the screen first drew, so slow launches can be traced to the right step.
