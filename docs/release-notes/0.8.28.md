Ferret 0.8.28

- SSH projects: you can now delete, rename, move and copy files and folders from the file tree on the right, as in local projects (right-click, Delete / ⌘⌫, F2, cut / copy / paste, duplicate, dragging within the tree, and Undo). Deleted items are moved to the Trash on the remote machine (usually ~/.local/share/Trash), so you can restore them from there, for example from the Trash in Ubuntu's Files app. Items on a different disk from that Trash are not moved; delete them in the terminal. Reveal in Finder, Open in Terminal and adding files from this computer are not available for SSH projects.
- SSH projects: dragging files from the file tree into a terminal now inserts their paths on the remote machine, and dropping them on the editor opens them.
- SSH projects: scrolling up with the mouse wheel in a terminal or agent tab now scrolls back through the output instead of bringing up the agent's earlier prompts, and typing right after scrolling goes to the agent as in local tabs. Ferret turns on mouse support only for its own tmux session on the remote machine (your other tmux sessions and settings are not changed); dragging now selects and copies with tmux, so hold Option (macOS) or Shift (Windows / Linux) to select with Ferret instead. Tabs that are already open pick this up the next time they reconnect.
- SSH projects: commands for the file tree, saving and the folder picker are now sent to the remote machine on standard input instead of the command line read by the login shell, so file names with quotes or backslashes are handled safely even when the remote login shell is fish or tcsh.
