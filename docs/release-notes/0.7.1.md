Ferret 0.7.1

- Hermes Agent and OpenClaw, the two agents DeepSeek documents for its models, are now listed among the main agents in onboarding and in Settings > Agents, so you can start them in a terminal without searching the full list.
- Sending to Hermes Agent and OpenClaw from Ferret now presses Enter after pasting, so your request is sent, as with Claude Code and Codex. Shift+Enter inserts a new line in both.
- Agent mail: `ferret-agent send hermes` and `ferret-agent send openclaw` reach them (the old name `clawdbot` also works).
