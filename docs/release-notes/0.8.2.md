Ferret 0.8.2

- New Value use cases tab (right of Visual review): the agent first writes why the system exists, each value a user gets, and the full click-by-click flow from the first screen, with the target button marked on the latest screenshot and whether each flow works yet. Approve it and the agent builds the system to match; when every flow works, the system is complete.
- Visual review and Value use cases: give feedback by voice and drawing, not only by typing. Press "Voice and drawing feedback", talk and mark the screenshot; when you stop, the findings, transcript and screenshots go to the agent that wrote the plan.
- Browser, Findings, Visual review and Value use cases now sit in their own row above the file tabs, so open files get the full row.
- Ferret no longer stops idle Claude Code or Codex tabs on its own to free memory. When memory runs low, it shows an alert listing what uses the most (agents, terminals, the built-in browser) so you can choose what to stop; stopped agents can be resumed where they left off.
- Visual review and Value use cases: feedback can be sent at any time, also after approval or while the agent is building (approval is still only for plans waiting for an answer).
