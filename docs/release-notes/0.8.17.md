Ferret 0.8.17

- On Windows, the review now appears much sooner after you stop a recording. Local transcription (whisper.cpp) used only 4 CPU threads; it now uses about half of your CPU's threads (4 to 16), which was more than twice as fast in testing. When whisper.cpp has no GPU support, Ferret prefers the faster large-v3-turbo-q5_0 model if you have downloaded it, and the transcription settings say that it is running on the CPU and how to install a GPU build (CUDA for NVIDIA, Vulkan for AMD and Intel).
- Fixed a crash on Windows where Ferret could close by itself while browser-use was driving the built-in browser, for example when switching projects. Requests from browser-use to change the page's screen size are now accepted without being applied; Ferret sets the size of the built-in browser itself.
- Fixed the trimmed version of a recording (with the idle parts removed) not being made when you switched to another project before the review was ready. Importing a meeting recording is no longer affected by switching projects either.
