Ferret 0.8.29

- SSH projects: the file tree now picks up files and folders created, deleted or renamed on the remote machine (for example by a terminal or an agent) within about a second and a half, without pressing Refresh. Ferret checks only the folders you have open, in one SSH request, and pauses while the window is hidden.
- SSH projects: images, PDFs, videos and audio files now open in the viewer as in local projects. Videos can be seeked; Ferret reads them from the remote machine a part at a time. Images in Markdown previews are shown too.
- SSH projects: right-click a file or folder and choose Download to save it to your Downloads folder (it is shown in Finder or Explorer; a name that already exists gets " (2)" added). Upload Files… and Upload Folder… send files from this computer to the folder you right-clicked, and dragging files from Finder or Explorer onto the tree uploads them too. Uploads never overwrite: if a file with the same name is already there, nothing is uploaded. Pasting from the system clipboard is still not available for SSH projects.
- The file tree's right-click menu now has Refresh.
