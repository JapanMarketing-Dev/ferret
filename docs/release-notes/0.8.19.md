Ferret 0.8.19

- New Design system tab, next to Value use cases. It shows the open project's Storybook inside Ferret. If Storybook is set up but not running, Start runs it in a Ferret terminal. If the project has none yet, "Ask the agent to build it" sends the request to your agent. A new agent skill, ferret-design-system, makes a Storybook design system (tokens and every component in every state) a required part of every project with a UI, and has screens built only from it.
- Past feedback works harder, so the first version needs fewer corrections. The ferret-feedback list now starts with the feedback that keeps coming back, written as rules (for example "remove what is not needed", "too much text", "everything must work"), followed by what people approved. Filler fragments from speech-to-text are dropped, one busy project no longer pushes the others out, and the list is refreshed shortly after new feedback arrives instead of only at startup. Agents now check their work against these rules before showing it, and fix a recurring issue in the design system so it does not come back.
- Visual review plans and value use-case documents can list "Applied from past feedback", so you can see which of your earlier points were handled up front.
