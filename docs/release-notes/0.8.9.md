Ferret 0.8.9

- Settings › Accounts now shows usage for every account: each limit (5 hours, week, Fable) with a bar, the percentage, and when it resets (date and time, plus how long until then).
- Accounts you added but are not using now show their usage too, instead of "waiting for login refresh". Ferret refreshes their expired sign-in the same way Claude Code does and saves it back.
- The same login is listed once, in Settings and in the footer's account list (for example, an added account that is the same as your usual login, or the same account added twice).
- An organization that does not allow Claude OAuth sign-in now says so, instead of showing it as waiting for a refresh.
- Recording the whole screen no longer shows Ferret's preview inside itself over and over: the part of the screen where the preview sits is blanked in the preview, so the recording stays clean.
