Install

Download Ferret for your computer and open it. It runs on macOS, Windows, and Linux.

#Download

The download page offers the right file for your computer. Click the download button.

#macOS

Open the .dmg, drag Ferret to Applications, and open it from there.

#Windows

Run the downloaded .exe. Ferret installs and opens, with nothing to choose. Next time, open it from the Start menu or the desktop shortcut.

If Windows shows Windows protected your PC, click More info, then Run anyway.

#Linux

Ubuntu / Debian: double-click the .deb to install it with your software center, or run:

sudo apt install ./Ferret-<version>-linux-amd64.deb

Then open Ferret from your app menu, or run ferret.

Other distributions: use the .AppImage. AppImages run with FUSE 2, so first install its package if your system does not have it: fuse-libs on Fedora, fuse2 on Arch, libfuse2 on openSUSE and Debian-based systems. Then allow the .AppImage to run as a program (right-click → Properties, or chmod +x) and open it.
