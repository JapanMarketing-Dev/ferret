## YouTube

Ferret は、あなたが「OK」を押したあとに動画をあなた自身のチャンネルへ投稿するために、YouTube API サービスを利用します。Google アカウントを連携することで、YouTube 利用規約に拘束されることに同意したものとみなされます。Google が扱うデータには Google プライバシー ポリシーが適用されます。アクセス権は Google のセキュリティ設定、または Ferret での連携の解除から、いつでも取り消せます。Ferret がこのアクセスをどう使うかはデータとプライバシーに書いています。
