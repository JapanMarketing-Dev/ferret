# サムネイル

- 構成は「完成した画面（結果）＋顔＋短い文字」。顔は右、画面は左〜中央、文字は上か左
- 画面は完成したもの・一番分かりやすい結果のフレームを `ferret-video frame` で取り出し、要点の部分だけを大きく切り出す。細かいコードの全体は小さい表示で読めないので使わない
- 顔は表情がはっきりしたフレーム（驚き、納得、笑顔）。目を閉じかけ・ブレているものは使わない
- 文字は 8〜12 字、2 行まで。できるようになること・結果を書く（例: 「5分で自動デプロイ」「設定はこれだけ」）
- ツール名・ロゴを入れるなら 1 つだけ。公式のロゴは利用規約で許されている範囲で使う
- 画面に個人情報（トークン、メールアドレス、社内の URL）が写っていないかを必ず確認する。動画のモザイクはサムネイルには掛からない
- 誇張・釣り（内容にないこと、「誰でも」「最強」）は書かない

## 作り方（API キーは使わない）
- 画像は、動画の内容（タイトル・要点・人物）から新しく作ってよい。動画のフレームをそのまま使う必要はない
- 画像生成は API キーで呼ばない。Codex（ChatGPT のサブスクリプションの画像生成 / gpt-image）か Gemini CLI（Gemini のサブスクリプション）に「1280×720 の YouTube サムネイルを作って thumbnails/thumb-1.png に保存して」のように頼む。人物を入れるなら `ferret-video frame --at <フレーム>` で顔のはっきりしたフレームを書き出し、参考画像として渡す
- できた画像を publish.json の thumbnail に書く（例: "thumbnail": "thumbnails/thumb-1.png"。プロジェクトからの相対パス）。`ferret-video thumb pick thumbnails/thumb-1.png` でも書ける。画像が存在すれば thumbnail の手順は終わる
- 文字を画像に入れるのが難しければ、`ferret-video thumb gen --provider frame --title "見出し"` で、元の画像に文字だけを入れられる
